# AI Core · Chaïma Ouerghi

A 3D scroll portfolio: as you scroll, a particle core changes shape through five steps (Input → Data → Learning → Intelligence → Action), each linked to real work.

**Live demo:** https://portfolio-ouerghi.vercel.app/

![Demo](docs/demo.gif)

## Features

- 3D particle core that morphs with the scroll
- Professional badge you can swing and flip
- Light / dark mode
- English / French

## Tech stack

React · Vite · Three.js (React Three Fiber) · GSAP ScrollTrigger · Lenis · Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173
